# Bộ demo

10 cặp ảnh PNG xám 8-bit và nhãn TIFF 16-bit từ BBBC038v1. Nền nhãn là 0, mỗi nhân có một ID nguyên dương. Đây là tập con test đã chốt, không dùng để chọn tham số hoặc huấn luyện.

Chạy `python scripts/setup_demo_data.py` từ thư mục gốc repo để kiểm tra checksum và chuẩn bị đường dẫn mặc định. Thông tin ID gốc và nhãn: `data/demo_manifest.csv`, `data/manifest.csv`. Nguồn dữ liệu: https://bbbc.broadinstitute.org/BBBC038
